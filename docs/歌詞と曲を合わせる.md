# 歌詞と曲を合わせる

時刻の付いていない歌詞から、**曲に合った時刻付きの歌詞（`.lrc`）を作る**手順です。
シナリオを AI が書く前提で、**その下ごしらえ**をするための道具立てになっています。

---

## なぜ要るのか

歌詞 MV でいちばん効くのは «歌詞が歌と合っていること» ですが、手元にあるのは
たいてい時刻の無いテキストです。

Movo にはもともと `.lrc` / `.srt` を**読む**口はありました（`movo/core/lyrics.py`）。
無かったのは **時刻を付ける**ほうです。そのため `make-mv` は歌詞を «小節数から
機械的に» 配っていました。曲の構成には追従しますが、«その行がいつ歌われるか» は
一切見ていません。

```
（前）  歌詞 ──小節数で等分──▶ MV        いつ歌うかは見ていない
（後）  歌詞 ──movo lyrics align──▶ .lrc ──▶ MV
```

---

## 3 手順

### 1. 下書きを作る

```bash
movo lyrics align song.mp3 --text lyrics.txt -o song.lrc --scenario scenario.json
```

歌詞は **空行でブロックに区切って**ください。空行はただの見た目ではなく、
**構造の情報**として使います（繰り返すブロック＝サビ、と判定します）。

出るもの:

| | |
| --- | --- |
| `song.lrc` | 時刻付きの歌詞。`make-mv` や素材（`"type": "lyrics"`）で読めます |
| `scenario.json` | シナリオを書くための下ごしらえ。区間・ブロック・間奏・要確認の行 |
| 画面 | ブロックごとの時刻、歌の無いところ、確からしさの低い行 |

### 2. ずれているところを留める

**自動の下書きだけでは合いません。**「木みたいな草だった」で試したところ、
エネルギー由来の区間が 15 個に対して歌詞ブロックは 7 個で、そもそも 1 対 1 に
対応しませんでした。音声認識を入れない以上、ここは避けられません。

そこで **数点だけ «この行はここ» と留める**と、あいだが配分し直されます。

```bash
movo lyrics align song.mp3 --text lyrics.txt \
  --anchor 1=5.4 --anchor 5=31.4 --anchor 17=88.5 -o song.lrc
```

- `--anchor <行番号>=<秒>`。行番号は **1 始まり**
- 行の頭の文字でも指定できます（`--anchor 木だと思ったけど=31.4`）
- 留めた行はその時刻ちょうどに来て、拍へのスナップもされません

**28 行を全部打つのと、3〜5 点だけ留めるのとでは手間が桁で違います。**
これがこの仕組みの本体で、自動の下書きはその出発点にすぎません。

留める場所は、画面に出る «要確認» の行と、各ブロックの 1 行目が効きます。

### 3. MV にする

```bash
movo make-mv song.mp3 --lyrics song.lrc --title 曲名 --jobs 6 -o mv.mp4
```

`--lyrics` を渡すと、小節数で配るのをやめて **実際に歌われる時刻**で
カットへ割り当てます。間奏のカットには «歌詞なし» が明示されます。

---

## 中で何をしているか

1. **曲の構造** — `analyze_audio` の BPM・拍・区間
2. **歌詞の構造** — 空行でブロック、繰り返し（類似度 0.82 以上）をサビと判定
3. **歌う範囲** — 中域（200〜2000Hz）が全体に占める比率から «声が乗っていそうな»
   ところを拾い、イントロ・間奏・アウトロを配分の対象から外す
4. **ブロックの中** — 行を **モーラ数**で割り付け、頭を最寄りの拍へ寄せる

### モーラ数で割る理由

文字数で割ると漢字の行が短く出ます。「風に揺れる葉っぱの音」は 10 文字ですが
12 モーラです。日本語の歌はモーラがほぼ等間隔に乗るので、**モーラ数は文字数より
はっきり良い近似**です。

読みの分からない漢字は定数（`KANJI_MORAE = 1.8`）で近似します。辞書を持たない
以上これは当てずっぽうですが、1 文字 = 1 モーラとみなすよりは近い値です。

### 歌唱区間の見立ての限界

⚠ **音源分離ではありません。** 中域の濃いシンセやピアノが鳴っていれば «歌って
いる» と出ます。狙っているのは «イントロ・間奏・アウトロを外す» ことだけです。

実際の曲で確かめたところ、歌のところは 14〜23 秒の連続した塊になり、間奏は
0.7〜1.1 秒の細切れにしかならなかったので、**「長く続いているか」で分けるのは
うまく働きました**。それでも外したいときは `--no-gaps` か `--start` / `--end` で
範囲を直接指定してください。

---

## 音声認識を入れない理由

`core/lyrics.py` が音声認識を入れなかったのと同じ理由です。

- 外部 API に出すと **«依存ゼロ»** が壊れる
- 認識結果が実行ごとに変われば **«同じ JSON からは同じ動画が出る»** が壊れる

文字起こしは外でやって、その結果を `--text` から渡してください。
`.lrc` を持っているなら、そもそもこの手順は要りません（`make-mv --lyrics` へ直接）。
